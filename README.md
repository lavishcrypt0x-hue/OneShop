# OneShop

OneShop is a shopping marketplace app for new products from verified brands and sellers.

## Current version

Version 0.1

## Current features

- OneShop home screen
- Search field
- Product categories
- Featured product cards
- New-product labels
- Android-first design

## Planned features

- Product details
- Shopping cart
- Test checkout
- Customer orders
- Seller registration
- Seller product upload
- Admin product approval
- Payment integration
- Courier integration
- Brand and seller network integration

## Product rule

OneShop will list only new products.

Used, second-hand, refurbished, counterfeit, or previously owned products are not allowed.

## Technology

- Expo
- React Native
- JavaScript or TypeScript
- GitHub Codespaces
- Expo Go for Android testing

## Development status

This project is currently a prototype. It does not process real payments and does not connect to real delivery services.
