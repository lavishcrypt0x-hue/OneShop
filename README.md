📱 Project Goal

One Shop is a sample online shopping website designed to demonstrate how a modern e-commerce platform can work.

The project is being developed step-by-step with a focus on:

- Modern UI
- Mobile-friendly design
- Product browsing
- Product details
- Shopping cart
- Checkout
- Demo orders
- Wishlist
- User profile
- Order history

💾 Data Storage

The current prototype uses the browser's Local Storage for demo data.

Example storage:

oneShopCart
oneShopOrders
oneShopLastOrder

This means the current shopping cart and demo orders are stored locally in the user's browser.
